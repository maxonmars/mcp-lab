# Первый старт

Цель: показать изоляцию агента, работу CLI/REPL и настройки без прежних фич.
Ожидаемые ответы модели не являются фактически измеренными результатами.

## Без API

Из корня репозитория:

```sh
npm run dev -- help
npm run dev -- config show
npm run check:deps
```

Показать общую справку, источники настроек, отсутствие значения ключа и результат проверки границ.

## С моделью

Ключ заранее задан в LAB_LLM_API_KEY; значение не показывать на записи.

```sh
npm run dev
```

```text
Объясни роль host в MCP одним предложением.
```

```text
/config show
```

```text
Назови два основных транспорта MCP. Ответь кратко.
```

```text
/exit
```

Ожидаемо: две независимые реплики вызывают по одному запросу; команды не обращаются к модели.
В текущем старте нет истории, поэтому сценарий не проверяет запоминание предыдущих реплик.

## Архитектурное нарушение

```sh
npm test -- tooling/tests/dependencies.test.ts
```

Тест создаёт временный проект, добавляет запрещённый межфичевый импорт,
проверяет ненулевой код, удаляет импорт и повторно проверяет корректный граф.
Рабочие файлы приложения при этом не изменяются.
