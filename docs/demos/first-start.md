# Первый старт

Цель: показать изоляцию агента, работу CLI/REPL и настройки. Раздел «Без API» не обращается к
MCP-фиче; в разделе «С моделью» `ask` всегда запускает и закрывает сессию собственного Open‑Meteo MCP
(см. [демо вызова инструмента](open-meteo-tool.md)), но обычные вопросы не приводят к tool call.
Ожидаемые ответы модели не являются фактически измеренными результатами.

## Без API

Из корня репозитория:

```sh
npm run dev -- help
npm run dev -- config show
npm run check:deps
```

Показать общую справку, источники настроек, отсутствие значения ключа и результат проверки границ.
Справка выводится блоком `── Справка ──` с частями «Команды» и «Настройки»; config show — блоком
`── Настройки ──`, где у каждого ключа есть значение и источник. Без ключа в окружении и корневом `.env`:

```text
── Настройки ──

config.file          lab.config.yaml                 (default)
llm.model            deepseek-flash                  (default)
llm.timeoutMs        30000                           (default)
llm.maxOutputTokens  1024                            (default)
llm.apiKey           [не задано]                     (default)
mcp.filesystemRoot   docs/demos/fixtures/filesystem  (default)
mcp.timeoutMs        10000                           (default)
```

При заданном ключе строка llm.apiKey показывает только `[задано]` и источник.
Ошибка аргументов оформляется так же, как ошибка команды, и уходит в stderr с кодом 1:

```sh
npm run dev -- --llm-timeout-ms=abc help
```

```text
Ошибка · Некорректная настройка llm.timeoutMs (источник: cli).
```

## С моделью

Ключ заранее задан в LAB_LLM_API_KEY; значение не показывать на записи.

```sh
npm run dev
```

REPL один раз показывает заголовок `── mcp-lab ──` с подсказкой о командах, затем пурпурное
приглашение `mcp-lab >` перед каждым вводом. Ответ модели выводится блоком `── Ответ агента ──`.
При вводе через pipe заголовок и приглашение не печатаются.

```text
Объясни роль host в MCP одним предложением.
```

```text
/config show
```

```text
Назови два основных транспорта MCP. Ответь кратко.
```

```text
/exit
```

Ожидаемо: две независимые реплики вызывают по одному запросу; команды не обращаются к модели.
В текущем старте нет истории, поэтому сценарий не проверяет запоминание предыдущих реплик.

## Архитектурное нарушение

```sh
npm test -- tooling/tests/dependencies.test.ts
```

Тест создаёт временный проект, добавляет запрещённый межфичевый импорт,
проверяет ненулевой код, удаляет импорт и повторно проверяет корректный граф.
Рабочие файлы приложения при этом не изменяются.
