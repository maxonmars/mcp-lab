# Совет по одежде: три MCP-инструмента одного сервера

Цель: показать цепочку `get_current_weather → recommend_outfit → save_outfit_advice` через одну MCP-сессию
Open‑Meteo — командой и через `ask` — и проверить сохранённый `latest.md`.

## Требования

- установленные зависимости (`npm ci`);
- `LAB_LLM_API_KEY` в окружении или корневом `.env`;
- сеть для Open‑Meteo и DeepSeek.

## Команда

Из корня репозитория:

```sh
npm run dev -- outfit Новосибирск
```

Перед советом печатаются три строки статуса, после совета — путь файла:

```text
MCP: get_current_weather — выполнено
MCP: recommend_outfit — выполнено
MCP: save_outfit_advice — выполнено

── Совет по одежде ──

# Что надеть сейчас
...
## Данные о погоде, на которых основан совет
...
Сохранено: <cwd>/.local/outfit/latest.md
```

## Через ask

```sh
npm run dev -- ask "Что надеть в Новосибирске, если выхожу на пару часов?"
```

Если модель выбрала фасад `prepare_outfit_advice`, печатаются те же три строки `MCP:`, затем ответ агента.
Фасад сам строку статуса не печатает. Выбор делает модель, поэтому гарантированный порядок даёт команда.

## Проверка latest.md

```sh
head -n 20 .local/outfit/latest.md
```

Файл содержит заголовок `# Что надеть сейчас`, совет модели и раздел с исходным текстом погоды, включая
три почасовых интервала. Повторный успешный запуск заменяет файл; временных `*.tmp` рядом не остаётся:

```sh
ls .local/outfit
```

## Сценарий ошибки

```sh
npm run dev -- outfit Плюторандия
```

```text
MCP: get_current_weather — ошибка
Ошибка · Шаг «погода и прогноз» не выполнен: Место не найдено сервисом геокодирования Open-Meteo.
```

Код выхода 1; модель не вызывается, `latest.md` не меняется.

## Подтверждение

Все три сценария выполнены вручную 2026-09-25 с настоящими Open‑Meteo и DeepSeek (`deepseek-flash`).
Измерено: три строки `MCP:` в указанном порядке для команды и для `ask`; `latest.md` создан командой и
заменён запуском `ask` (изменилась контрольная сумма, в каталоге только `latest.md`); ошибочный город дал
код 1 и одну строку статуса, файл не изменился. Фрагмент прогноза из сохранённого файла:

```text
Прогноз на ближайшие часы (местное время, Asia/Novosibirsk). Состояние, температура и ветер — на момент отметки; осадки и их вероятность — за час перед отметкой.
- 2026-09-25T14:00: пасмурно; температура 12.8°C (ощущается как 9.2°C); ветер 17.5 км/ч; осадки за час до отметки 0 мм, вероятность осадков за этот час: 1%.
```

Числа и текст совета меняются между запусками. Содержание совета сервер не проверяет, кроме непустоты и
завершённости ответа: в одном из запусков модель вставила в русский текст иероглифы вместо слова.
