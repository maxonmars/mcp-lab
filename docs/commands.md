# Команды

Генерируется из реестра: `npm run docs:generate`.

CLI: `npm run dev -- <команда>`. Без команды запускается REPL; обычная строка вызывает ask.
CLI-флаги задаются при запуске. В REPL настройки не изменяются.
CLI использует quoting оболочки; в REPL остаток /ask передаётся как текст без обработки кавычек.

| CLI | REPL | Описание |
|---|---|---|
| ask <текст...> | /ask | Отправить независимую реплику агенту. Для актуальной погоды агент может вызвать доступный Open‑Meteo MCP-инструмент. |
| help | /help | Показать команды и флаги настроек. |
| config show | /config show | Показать действующие настройки и их источники без значений секретов. |
| mcp tools | /mcp tools | Получить список инструментов локального Filesystem MCP без обращения к модели. |
| exit | /exit | Завершить ввод реплик. |

Алиасы help: --help, -h.
Чтобы передать текст, начинающийся с --, используйте `ask -- <текст>`.
