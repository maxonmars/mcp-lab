# MCP-серверы

Зарезервировано для будущих заданий. Серверов и зависимости MCP SDK сейчас нет.

Каждый реализованный сервер станет отдельным npm workspace с package.json, README.md,
AGENTS.md, CLAUDE.md, src/index.ts, src/app/main.ts, tsconfig.build.json и собственными тестами.
README должен содержать запуск, конфигурацию, Inspector и фрагменты подключения реальных клиентов.
Версии клиентов и ревизию протокола отмечать проверенными только после фактической проверки.

Серверы не импортируют host и друг друга. Для тестов использовать подменённые API и транспорт.
При появлении сервера обновить проверки его запуска в tooling/build.ts.
