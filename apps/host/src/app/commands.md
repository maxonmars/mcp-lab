# Описания команд

## ask
Отправить независимую реплику агенту.

## help
Показать команды и флаги настроек.

## config show
Показать действующие настройки и их источники без значений секретов.

## mcp tools
Получить список инструментов локального Filesystem MCP без обращения к модели.

## exit
Завершить ввод реплик.
