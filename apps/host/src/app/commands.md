# Описания команд

## ask
Отправить независимую реплику агенту. Для актуальной погоды агент может вызвать доступный Open‑Meteo MCP-инструмент.

## help
Показать команды и флаги настроек.

## config show
Показать действующие настройки и их источники без значений секретов.

## mcp tools
Получить список инструментов локального Filesystem MCP без обращения к модели.

## scheduler run
Запустить worker планировщика в этом процессе до Ctrl+C: опрос погоды по расписаниям и печать опубликованных сводок. Нужен LAB_LLM_API_KEY.

## scheduler summary
Показать последнюю сохранённую сводку по городу или ID расписания через MCP без обращения к модели.

## exit
Завершить ввод реплик.
