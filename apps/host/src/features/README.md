# Фичи host

`mcp/` получает список инструментов установленного Filesystem MCP. Новые фичи добавляются только по заданию.

Каталог `<name>/` содержит `index.ts`, `README.md`, `tests/*.test.ts`.
Инструкции модели при необходимости находятся в `prompts/*.md`.
В README: назначение, публичный контракт, настройки, команды, ограничения и способ проверки.
Реализация и специфические адаптеры остаются внутри фичи; снаружи импортируется только index.ts.
Фичи не импортируют друг друга. Регистрация выполняется в app/compose.ts.
Если нужного контракта ядра нет, сначала предлагается ADR.
Пустые фичи для будущих заданий не создавать.
