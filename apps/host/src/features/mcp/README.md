# MCP: список инструментов Filesystem

## Назначение

Фича запускает локальный Filesystem MCP через stdio, получает сведения о сервере и список его
инструментов, затем закрывает соединение. Она не вызывает инструменты и не обращается к модели.

## Публичный контракт

`discoverFilesystemTools(options)` принимает абсолютный `root`, таймаут MCP-запросов и путь к
исполняемому Node. Возвращаются только имя и версия, сообщённые MCP-сервером, а также имена и
неизменённые описания инструментов. SDK, транспорт и дочерний процесс остаются внутренними.

`McpDiscoveryError` содержит код причины; у ошибки `TIMEOUT` есть `stage`: `connect` или
`listTools`. Пользовательский текст формирует CLI.

## Настройки и команда

Composition root передаёт значения `mcp.filesystemRoot` и `mcp.timeoutMs` в операцию фичи.
Команда host — `mcp tools`; в REPL ей соответствует `/mcp tools`.

## Ограничения

Для каждого запуска создаётся новое соединение. Поддерживается только один локальный Filesystem
server и transport stdio. Roots, resources, prompts, sampling, вызовы инструментов, кэш и
переподключение в эту фичу не входят.

## Проверка

Тесты фичи проверяют успешный и ошибочные жизненные циклы через подмену SDK, а интеграционный
тест запускает установленный Filesystem server во временном каталоге. Полная проверка проекта:
`npm run check`.
