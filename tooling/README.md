# Проверки репозитория

- `dependencies.ts`, `dependency-rules.ts`: dependency-cruiser, публичные входы и направления импортов.
- `size.ts`: AST и строки с токенами кода; пределы заданы в limits.
- `structure.ts`: размер, шаблоны фич/workspaces, пары AGENTS/CLAUDE, доступ к process.
- `docs.ts`: генерация и проверка Markdown из реестров.
- `build.ts`: сборка пакетов, копирование Markdown, проверка CLI из другого каталога.
- `tests`: положительные и отрицательные примеры для проверяющих инструментов.

`npm run check` одинаков для pre-commit и CI. Отдельных ослабленных правил для тестов зависимостей нет.
Не добавлять broad ignore или baseline нарушений. Изменение границ и исключения проходят ADR.
Семантика промптов, назначение портов и достаточность тестов дополнительно проверяются review.
